Instructions for using Puffin

Getting started with PUFFIN is easy!

How to Use

Low-Latency Remote Control

The Puffin module utilizes WebRTC technology to ensure ultra-low latency video and control transmission, allowing you to seamlessly control drones, RC cars, robotic arms, and other devices from anywhere in the world.

Multi-Mode Network Support

Supports 4G LTE, WiFi, and GPS, ensuring stable remote communication. It also features point-to-point WiFi direct connection, making it suitable for both indoor and outdoor applications.

Plug & Play, Easy to Use

No complex programming required—ready to use out of the box. Comes with a Web App control interface, compatible with PCs, tablets, and smartphones, allowing you to control your devices anytime, anywhere.
